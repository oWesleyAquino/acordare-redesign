ACORDARE v1.4 — HERO + CORREÇÃO DE FOTOS

1. Faça backup da pasta atual.
2. Na pasta do seu projeto no VS Code, substitua os seguintes arquivos pelos do ZIP:
   app/page.tsx
   app/globals.css
   lib/data.ts
3. Crie components/hero-slider.tsx com o arquivo correspondente do ZIP.
4. Salve. O npm run dev recarrega automaticamente.

NOVO HERO:
- 3 banners com títulos e imagens diferentes
- troca automática a cada 7 segundos
- imagem alterna com crossfade + zoom sutil, títulos entram suavemente
- botões mantidos fora do bloco de texto alternado
- pausa quando o cursor entra ou teclado foca o carrossel
- setas e indicadores clicáveis
- respeita reduced-motion

IMAGENS:
- Corrigida imagem de Dormitórios para fotografia de quarto real
- Aplica na Home, na galeria /ambientes, no carrossel editorial e terceiro banner
- A imagem de dormitório é ilustrativa, Unsplash, não um ambiente real da Acordare.
- As outras imagens mantêm vínculos do site oficial e deverão ser revisadas visualmente antes de publicar.

Não é necessário executar npm install novamente.
